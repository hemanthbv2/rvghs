🔍 3. Free-Text Keyword Matching (NLP)

The bot utilizes a hardcoded dictionary mapping user input substrings to specific decision tree nodes, enabling a pseudo-AI conversational experience.

Trigger Node Target Keywords (Substrings)
admissions admission, apply, enroll, registration, join, seat
fees fee, cost, price, payment, amount
contact phone, email, address, location, map, human, speak
faq_timings uniform, dress, timing, schedule, hour
midday meal, lunch, food, canteen, tiffin, akshaya

🛡️ 4. Content Moderation & Security

A built-in Regex-based content moderation engine strictly prevents the bot from engaging in inappropriate topics.

Category Description / Example Triggers Bot System Response
Abusive Profanity, harassment, violence, explicit terms. "I'm unable to respond to inappropriate language. Please keep our conversation respectful."
Conspiracy Political, fake news, unverified claims (e.g., 'illuminati', 'flat earth'). "I'm designed to provide factual info about the school only. I cannot engage with unverified claims."
Private Data Queries about student marks, teacher salaries, personal phone numbers, or passwords. "I cannot share personal or confidential information about students, faculty, or staff."

🎯 5. Global System Rules

  • Rules-Based Execution: The system relies entirely on predefined decision trees and keyword maps. No generative AI or external API calls are made for responses, guaranteeing 100% brand-safe answers.
  • Institution Context Switch: A single codebase powers three separate school chatbots by dynamically injecting the data model (SCHOOLS object) based on the URL context or initialization parameter.
  • Graceful Fallback: If free-text input does not match any keyword, the bot politely apologizes and re-presents the Main Menu buttons to guide the user back into the flow.
  • Local Telemetry: Chat interactions, unmatched queries, and feedback are logged locally (rvce_standalone_logs) to help administrators identify missing keywords and improve the bot over time.
  • Contact Deflection: Pricing/Fee structures are intentionally withheld from the bot to drive warm leads directly to the admissions office via phone or email.
